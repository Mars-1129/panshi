# 提示词 04 · 视觉、动效与可访问性验收 v2

> 每次交付前，把下面内容发给执行 Agent 做独立验收（只看不改，问题分级返回）。

```text
你是独立 QA。请对照 ui-kit-v2 素材包，对当前实现做交付前验收，先读
references/design-system.md、references/motion-and-interaction.md、references/accessibility.md，
以及 docs/specs/261028-lightweight-code-agent/frontend/implementation-checklist.md。

【验收维度，逐项给“通过/不通过 + 证据”】
1. 令牌一致性：是否只用 var(--rp-*)，无裸 hex、无平行系统、无重复 @media、无金色/衬线残留。
2. 玻璃与氛围：玻璃是否单层、发丝边、含 -webkit- 前缀与不透明回退；氛围是否不压内容、
   不随状态改色温；是否存在玻璃堆叠或所有卡片持续脉冲/漂浮。
3. 动效与反馈：入场/交错/骨架/脉冲是否符合 motion-and-interaction；只动 transform/opacity；
   骨架是否结构对齐并在数据到达后移除；Toast 是否仅轻反馈、不遮挡 CTA、live 区域正确。
4. 组件与状态：9 任务状态、6 tone、5 检查、5 严重级别、3 计划步骤、3 文件 kind 是否齐全；
   每个交互是否覆盖 loading/empty/error/success/disabled/blocked/offline。
5. 破坏性动作：是否两步确认、armed 可 Esc/失焦复位、第二次点击才执行；有无一次点击直接删除。
6. 数据诚实：状态是否来自 runtime/SSE + view-model，有无假计时器/假入口/伪造成功。
7. 响应式：375/768/1024/1440 下 reflow 正常，局部横向滚动不导致页面整体溢出。
8. 可访问性：语义地标、单一 h1、焦点可见不被遮挡、可访问名称、ARIA、live/alert、触控目标
   ≥44px、对比度 AA、reduced-motion 下无持续动画。
9. 构建质量：typecheck、build、test 结果；主题/布局切换是否闪烁或布局跳动。

【产出】
- 按“阻断 / 重要 / 建议”分级的问题清单，每条含复现路径、证据位置、违反的 ui-kit-v2 规则。
- 给出总体结论：可交付 / 需修复；不要把未验证项写成通过，不要给没有证据的结论。
```
