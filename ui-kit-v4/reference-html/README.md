# reference-html · 外部概念前端参考（隔离区，非产品样式）

本目录是一套**概念性前端页面**的原样存档，用于在信息架构、组件模式、交互细节与数据口径
表达上提供参考。它**不是产品 UI 的一部分**，也不接入 `css/styles.css` 聚合链。

## 为什么隔离

- 这套页面是另一套视觉语言（framed sheet：系统字体、`#0071e3` 强调色、1px 细边框、
  GSAP 动效），与本产品权威的蓝紫 `--rp-*` 体系（见 `tokens/tokens.css`）不一致。
- 因此**只借结构、概念、信息组织与交互模式**，不复制其颜色、字体、圆角、阴影与动效实现；
  任何落地都必须用 v4 的 `var(--rp-*)` 与既有类名重绘。
- 禁止在产品代码里 `import`/`<link>` 本目录的 `styles-final.css`，禁止引入 GSAP
  （产品动效只用 CSS，见 `css/motion.css`），禁止把本目录的类名带进 `App.tsx`。

## 文件清单（可直接双击打开，纯浏览器本地运行）

| 文件 | 内容 | 参考价值 |
|---|---|---|
| `index-final.html` | 三栏软件工厂工作台（5 工段 pill 导航 + 左右栏 + 主区） | 三栏外壳、工段 pill、输入源/智能体列表、工段进度管道、命令/日志/主题入口 |
| `prototype-demo.html` | 国企采购审批高保真页（内嵌独立样式） | KPI 口径注、表格 tfoot 合计、筛选、侧栏统计、快速操作、tabular-nums |
| `prototype-view.html` | 原型查看器（iframe + 桌面/平板/手机设备切换） | 设备预览框、分段滑动指示器、浏览器框 chrome |
| `styles-final.css` | framed-sheet 完整样式系统（约 4000 行） | 组件分区与状态写法的参考，**不直接引用** |
| `app-final.js` | 工作台交互逻辑（本地演示数据） | 交互编排、日志/演示流程的参考，**不直接引用** |
| `vendor/gsap.min.js` | GSAP 动画库 | 仅支撑参考页运行，**禁止引入产品** |

## 怎么用（正确姿势）

1. 先在浏览器打开 `index-final.html`，点顶栏「演示流程」、切工段、开运行记录，感受整体组织。
2. 打开 `prototype-demo.html` 看数据口径如何表达（每个 KPI 都有口径说明、表格有合计行）。
3. 打开 `prototype-view.html` 看设备切换与原型框。
4. 然后回到 `references/external-html-patterns.md`：那里把可吸收的模式逐条列好，
   并给出**在 v4 里用哪个类、用哪些 `--rp-*` 重绘**的映射，以及禁止照搬清单。
5. 落地时只按该映射文档与 v4 既有规范执行，不回头抄本目录的视觉值。
