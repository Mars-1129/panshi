# 页面地图与响应式 v2

## 1. 信息架构现状

当前前端是**单页状态切换**（`NavView`），尚未引入真实路由：

- `navView: "workspace" | "templates" | "settings"` 决定主区域渲染。
- 任务工作区内部用 `activeTab: TaskTab` 切换六个视图。
- 任务通过 `activeTaskId` 选中；`showComposer` / `commandOpen` 控制浮层。

后续若引入路由，可按 `docs/specs/.../frontend/page-map.md` 演进（`/`、`/tasks/new`、
`/tasks/:id`、`/templates`、`/settings`），但组件与 token 不变。

## 2. 桌面三段式骨架

```text
┌────────────────┬───────────────────────────────┬──────────────────┐
│ WorkspaceRail  │ ContextBar（顶部，56px）        │                  │
│  248px         ├───────────────────────────────┤  EvidenceRail    │
│                │  主工作面（minmax(0,1fr)）      │  300px           │
│  品牌/导航/    │  计划 / 运行 / diff / 检查      │  状态/检查/风险  │
│  最近任务      │                                │  /worktree       │
└────────────────┴───────────────────────────────┴──────────────────┘
```

- 左侧栏固定 248px；中间 `min-width:0` 保证可收缩；右侧证据栏 sticky 可滚动。
- 上下文条横跨主区域顶部，不进入左右栏。
- 整个 `.app-shell` 之上叠有固定的氛围层（网格/光晕/暗角），只在留白处可见。

## 3. 页面骨架

### 3.1 工作区首页（无任务）

```
.page-head（eyebrow + h1 + 说明）
.home-panel（图标 + 文案 + 模型/仓库/预算 facts + 新建按钮）
.home-notes（当前版本边界）
```

### 3.2 任务工作区

```
.page-head（面包屑 + 标题 + 状态徽章 + 元信息行）
.status-band（可选，当前状态/下一步/CTA）
.task-layout
  ├─ .task-main：.task-tabs + 当前 tabpanel
  └─ .evidence-rail：状态/检查/风险/worktree 卡片
```

### 3.3 模板 / 设置

- 模板页：未实现，仅诚实空态，不提供无法执行的入口。
- 设置页：只读展示运行时事实 + 主题切换。

## 4. 环境层与氛围层

v2 不使用 OmniDirector 的 `data-scene`（不随状态改色温），只保留固定的氛围背景层：

| 层 | 挂载 | 内容 | 约束 |
| --- | --- | --- | --- |
| 网格 | `.app-shell::before` | 32px 低强度网格，顶部 mask 局部显示 | 强度 5%，不压内容 |
| 光晕/暗角 | `.app-shell::after` | 右上主色光晕 + 底部暗角 | 光晕 ≤12%，固定不滚动 |

三种语义环境（workspace / review / setup）只影响内容编排，不改变交互合同、状态色与组件语义。

## 5. 玻璃材质的落点

- 推荐：命令面板、Toast、可选的粘性状态带、局部浮层。
- 上下文条默认保持实体 `--rp-surface`（保证可读性）；如需玻璃化，须验证文字对比度并提供降级。
- 普通内容面板不玻璃化；同一视图最多一层玻璃。

## 6. 响应式断点（统一三档）

| 断点 | 结构 | 关键处理 |
| --- | --- | --- |
| `>= 1200px` | 三列工作台 | 左栏 + 主面 + 证据栏全显示，证据栏 sticky |
| `860–1199px` | 证据栏下沉 | 单列主面 + 证据栏转 3 列网格；隐藏 worktree 静音卡 |
| `640–859px` | 左栏转抽屉 | 工作区栏固定隐藏，汉堡拉出；隐藏 context-meta；状态带 CTA 占满 |
| `<640px` | 手机单列 | 命令框收缩为图标；tab 可换行；报告/证据单列；Toast 贴边 |

实现用 `max-width: 1199 / 859 / 639`，全部集中在 `layout.css`，不重复定义断点。

## 7. 窄屏规则

- 代码、diff、命令输出不压缩到不可读：允许局部横向滚动，但页面整体不横向溢出。
- 手机端主动作、返回、审批、取消必须可达；浮层用 sheet/对话框，不遮挡焦点。
- 触控目标 ≥44px（`--rp-touch-target`）；Toast 不遮挡关键 CTA。
- 375 / 768 / 1024 / 1440 四个典型宽度都要验证。

## 8. 页面状态（每个页面都要覆盖）

| 状态 | 表现 |
| --- | --- |
| 空仓库 | 说明未识别到什么，提供"创建任务/选择目录" |
| 加载中 | 骨架占位（结构对齐真实内容），可取消 |
| 计划生成中 | 当前阶段 + 取消入口 |
| 待审批 | 动作、影响范围、权限；`.attention` 轻提示 |
| 运行中 | 时间线更新但不抢焦点 |
| 断线 | 保留已知状态，显示重连，不伪装失败 |
| 失败 | 保留输入、命令、退出码、下一步 |
| 完成 | 结果、验证证据、风险、继续修复入口 |
